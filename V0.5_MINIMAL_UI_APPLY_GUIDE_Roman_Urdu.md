# Biillliiii's Inspector v0.5 — Minimal Professional UI Update

## Is patch mein kya badla hai?

Yeh patch sirf v0.5 development copy ke user interface ko update karta hai:

1. App khulne par public Welcome/Home page dikhega.
2. Welcome page par Log in aur Get started buttons honge.
3. Agar owner account abhi create nahi hua, buttons First-time Owner Setup kholenge.
4. Owner account banne ke baad buttons Login kholenge.
5. Login/Owner Setup page par Back to welcome option hoga.
6. Dashboard sirf successful authentication ke baad khulega.
7. Dashboard ka visual style dark demo theme se clean light/minimal professional style mein update hoga.
8. Existing project cards, memory, checklist, decisions, session history aur monitoring controls ke functional JavaScript ko redesign ke liye replace nahi kiya gaya.

## Kaun si files replace hongi?

- `ui/index.html`
- `ui/app.js`
- `ui/styles.css`
- `tests/auth-api.test.js` (Welcome-first initial screen ke liye test assertion update)

`data/projects.json`, `data/auth.json`, `monitoring` folder, `server.js` aur `auth.js` is UI patch mein shamil nahi hain.

## Apply karne ka tareeqa

1. v0.5 ka local server `Ctrl + C` se band karein. Agar poochha jaye to `Y` aur Enter dabayein.
2. ZIP ko Extract All karein aur destination yeh select karein:
   `C:\Programs  Pivates\Agent Start\Biillliiii_Inspector_v0.4_Automatic_Sessions\biillliiii_inspector_v5_development`
3. Agar Windows same-name files ka poochhe to **Replace the files in the destination** select karein.
4. Command Prompt mein v0.5 development folder se yeh commands chalayein:

   ```cmd
   npm run check
   npm test
   ```

5. Dono checks successful hon to:

   ```cmd
   npm start
   ```

6. Browser mein local link kholein aur `Ctrl + F5` se hard refresh karein.

## Expected behaviour

- Pehle Welcome/Home page dikhega.
- `Create owner account` / `Get started` first-time setup kholega.
- Account banne ke baad Welcome page ka CTA Login kholega.
- Dashboard, project data aur monitoring APIs login ke baghair available nahi honge.
