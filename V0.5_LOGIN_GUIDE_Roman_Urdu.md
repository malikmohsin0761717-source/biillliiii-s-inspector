# v0.5 Login-First — User Guide (Roman Urdu)

## Pehli baar app kholne par

1. Browser mein `http://127.0.0.1:4177` kholo.
2. `Create owner account` screen nazar aayegi.
3. Owner username aur 12+ character password set karo.
4. Create dabao. Recovery code display hoga.
5. Recovery code ko paper ya trusted password manager mein save karo. Kisi ko share na karo.
6. Checkbox tick karke confirm karo, phir login karo.

## Next launch

Har fresh app page launch par Welcome Back / Login screen aayegi. Agar pichla browser session active tha to nayi page load usay lock karegi; chalti monitoring safety ke liye pause hogi. Sahi username/password ke baad hi projects load honge.

## Logout aur auto-lock

- Top bar `Lock / Logout` press karne se workspace lock hota hai.
- 10 minute user inactivity par auto-lock hota hai.
- Agar monitoring chal rahi ho to lock/logout usay safety ke liye Pause karta hai. Login ke baad manually Resume karna hoga.

## Password bhool gaye?

1. Login screen par `Forgot password? Use recovery code` press karo.
2. Owner username aur saved recovery code enter karo.
3. Naya 12+ character password set aur confirm karo.
4. Naya recovery code display hoga. Purana code invalid ho jata hai; naya code save karo.
5. Login screen par naye password se login karo.

## Data safety

- Project data `data/projects.json` mein hi rehta hai.
- Owner credentials `data/auth.json` mein alag salted hashes ke roop mein store hote hain.
- v0.5 patch ZIP mein tumhara live `projects.json` include nahi kiya gaya.
- Login app/API access control hai, file encryption nahi. Windows account ko password se protect rakho.
